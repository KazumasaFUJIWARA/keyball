# Keyball44 my_keymap — レイヤー対応表

QMK のレイヤー番号は **0 始まり** です（L0, L1, L2 …）。

## レイヤー一覧

| QMK | 名称 | 開き方（基本） |
|-----|------|----------------|
| **L0** | ベース（QWERTY） | 通常入力 |
| **L1** | マウス・数字 | L0 の **F** 長押し / トラックボール自動 |
| **L2** | 記号・言語・特殊文字 | L0 の **D** 長押し |
| **L3** | ギリシャ文字 | **L2** + **Q** 長押し（MO(3)） |
| **L4** | イタalia語アクセント | **L2** + **W** 長押し（MO(4)） |
| **L5** | 数学記号（Unicode） | **L2** + **R の左** 長押し（MO(5)） |
| **L6** | 設定（RGB / CPI） | L0 の **G** または **H** 長押し |

## レイヤーの入れ子

```
L0（ベース）
 ├─ L1 … F 長押し（マウス）
 ├─ L2 … D 長押し（入力モード）
 │    ├─ F/G … 日本語 / 英数
 │    ├─ Q … MO(3) ギリシャ
 │    ├─ W … MO(4) イタalia語
 │    └─ Rの左 … MO(5) 数学記号
 └─ L6 … G/H 長押し（設定・スクロール）
```

## L2 入力モードレイヤー

L0 の **D** を押し続けて L2 に入る。

| 物理キー（L0 基準） | L2 での機能 |
|---------------------|-------------|
| **F** | `0x0090`（かな / 日本語入力） |
| **G** | `0x0091`（英数） |
| **Q** | MO(3) → ギリシャ文字 |
| **W** | MO(4) → イタalia語アクセント |
| **R の左** | MO(5) → 数学記号 |

**D を押し続けたまま、同じ左手**で Q/W 等を押す。

### 使い方の例

- **日本語:** `D` → `F`
- **ギリシャ（α）:** `D` → `Q` → `A` → 離す
- **∫:** `D` → `Rの左` → `G` → 離す

## L5 数学記号

L2 で **R の左** を押し続けている間、Unicode 記号が出力される（詳細は keymap.c 参照）。

## L6 設定レイヤー

L0 の **G**（左）または **H**（右）を長押し。RGB・CPI・スクロール設定用。
