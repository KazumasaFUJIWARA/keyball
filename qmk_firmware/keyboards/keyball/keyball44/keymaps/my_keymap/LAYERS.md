# Keyball44 my_keymap — レイヤー対応表

## ギリシャ α を出す手順

| 順番 | キー | 説明 |
|------|------|------|
| 1 | **D** 長押し | L2（記号レイヤー）に入る |
| 2 | **親指・3つ目** をタップ | OSL(3) ギリシャ（L2 の旧・全角半角エリア） |
| 3 | **TAB の右隣** | **α** が出る |

### 「親指・3つ目」とは

L2 の **一番下段（親指行）**、左から数えて:

| 左から | L2 での機能 |
|--------|-------------|
| 1番目 | `'` 付近（0x0027） |
| 2番目 | `.` |
| **3番目** | **OSL(3) ギリシャ** |
| **4番目** | **OSL(4) イタalia** |
| **5番目** | **OSL(5) 数学** |

L0 ではこの 3〜5 番目は別機能ですが、**D 長押し（L2）の間だけ**上記に変わります。  
日本語切替は **F / G**（ホーム行）のままです。

### OSL のコツ

OSL キーは **タップ1回** でよい。離したあと **次の1キーだけ** ギリシャ等になる。

```
D 押す → 親指3番目タップ → D 離してよい → TAB右隣で α
```

## Unicode が出ないとき（Windows）

- **英数（IME オフ）** にしてから
- **メモ帳** で試す
- **テンキー NumLock ON**
