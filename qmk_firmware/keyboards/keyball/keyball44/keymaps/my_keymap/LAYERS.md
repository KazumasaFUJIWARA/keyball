# Keyball44 my_keymap — レイヤー対応表

QMK のレイヤー番号は **0 始まり** です（L0, L1, L2 …）。

## レイヤー一覧

| QMK | 名称 | 開き方（基本） |
|-----|------|----------------|
| **L0** | ベース（QWERTY） | 通常入力 |
| **L1** | マウス・数字 | L0 の **F** 長押し / トラックボール自動 |
| **L2** | 記号・言語・特殊文字 | L0 の **D** 長押し |
| **L3** | ギリシャ文字 | **L2** を開いた状態で **H** 長押し（MO(3)） |
| **L4** | イタリア語アクセント | **L2** を開いた状態で **J** 長押し（MO(4)） |
| **L5** | 設定（RGB / CPI） | L0 の **G** または **H** 長押し |

## レイヤーの入れ子

```
L0（ベース）
 ├─ L1 … F 長押し（マウス）
 ├─ L2 … D 長押し（入力モード）
 │    ├─ F/G … 日本語 / 英数
 │    ├─ H … MO(3) ギリシャ
 │    └─ J … MO(4) イタリア語
 └─ L5 … G/H 長押し（設定・スクロール）
```

## L2 入力モードレイヤー

L0 の **D** を押し続けて L2 に入る。

| 物理キー（L0 基準） | L2 での機能 |
|---------------------|-------------|
| **F** | `0x0090`（かな / 日本語入力） |
| **G** | `0x0091`（英数） |
| **H** | MO(3) → ギリシャ文字（押している間） |
| **J** | MO(4) → イタリア語アクセント（押している間） |

### 使い方の例

- **日本語に切替:** `D` 長押し → `F`
- **英数に戻す:** `D` 長押し → `G`
- **ギリシャ1文字:** `D` 長押し → `H` 長押し → 文字キー → 離す
- **イタリア語1文字:** `D` 長押し → `J` 長押し → 文字キー → 離す

## L5 設定レイヤー

L0 の **G**（左）または **H**（右）を押し続けて L5 に入る。RGB・CPI・スクロール設定用。

L5 中はトラックボールが **スクロールモード** になる。

## L3 ギリシャ文字

QWERTY 配列に対応する小文字 Unicode（例）。

| 物理キー | 出力 | 例 |
|----------|------|-----|
| A | α | U+03B1 |
| B | β | U+03B2 |
| G | γ | U+03B3 |
| D | δ | U+03B4 |
| E | ε | U+03B5 |
| … | … | （ホームポジション中心に配置） |

## L4 イタリア語アクセント

| 物理キー | 出力 | 文字 |
|----------|------|------|
| A | U+00E0 | à |
| E（上段） | U+00E9 | é |
| F | U+00E8 | è |
| U | U+00F9 | ù |
| I | U+00EC | ì |
| O | U+00F2 | ò |
| P | U+00E1 | á |

## L0〜L1

L0〜L1 は Remap dump 由来の配列のまま。詳細は [`remap_dump/keyball44_keymap_dump.txt`](../../../../../../remap_dump/keyball44_keymap_dump.txt) を参照。

## ビルド・書き込み

```bash
bin/fetch-firmware.sh keyball44 my_keymap
```

取得した hex は `firmware/keyball44-my_keymap/` に `YYYYMMDD-HHMMSS_*.hex` として蓄積される（上書きしない）。最新は `latest.hex` シンボリックリンク。

Pro Micro Web Updater: https://sekigon-gonnoc.github.io/promicro-web-updater/  
右 `split-right` / 左 `split-left`。**左右両方**に同じ hex を書き込む。

## 変更履歴メモ

- L2 に言語（F/G）と L3/L4（H/J）を集約
- L5 は設定専用（L3/L4 の MO を削除）
- 言語キーは Remap dump 互換の `0x0090` / `0x0091`
