# Keyball44 my_keymap — レイヤー対応表

QMK のレイヤー番号は **0 始まり** です。

## レイヤー一覧

| QMK | 名称 | 開き方 |
|-----|------|--------|
| **L0** | ベース | 通常 |
| **L1** | マウス | F 長押し |
| **L2** | 記号・言語 | D 長押し |
| **L3** | ギリシャ文字 | L2 + 親指3番目 OSL |
| **L4** | イタリア語アクセント | L2 + 親指4番目 OSL |
| **L5** | 数学記号 | L2 + 親指5番目 OSL |
| **L6** | 設定（RGB/CPI） | G/H 長押し |

## L2 親指行（D 長押し中）

| 左から | 機能 |
|--------|------|
| 1番目 | `'` 付近 |
| 2番目 | `.` |
| **3番目** | **OSL(3) ギリシャ** |
| **4番目** | **OSL(4) イタリア語** |
| **5番目** | **OSL(5) 数学記号** |

OSL は **タップ1回**。離したあと **次の1キーだけ** 対象レイヤーになる。

## イタリア語文字を出す手順

| 順番 | キー |
|------|------|
| 1 | **D** 長押し（L2） |
| 2 | **親指・左から4番目** タップ（OSL(4)） |
| 3 | 母音キー（下表） |

### L4 の主な割り当て（UC）

| キー位置（QWERTY 基準） | 出力 |
|------------------------|------|
| A | à |
| E（上段） | é |
| F | è |
| U | ù |
| I | ì |
| O | ò |
| P | á |

例: **è** → `D` → 親指4番目タップ → `F`

## Unicode（Windows・Keyball 向けカスタム）

Keyball にテンキーがないため、QMK 標準の `register_unicode()` は使わず、
`keymap.c` の `register_unicode_numpadless()` が `UC()` を処理します。

- 方式: **Alt + `+`（メインキーボード）+ 4桁16進**
- 例: è (U+00E8) → Alt + + + `00E8`

### 試す前の設定

1. Windows キーボードレイアウトを **英語(米国)** にする（QWERTY 配列と一致させる）
2. **英数（IME オフ）** + **メモ帳** で確認
3. Windows 10 1903 以降を推奨
4. 未設定ならレジストリ `EnableHexNumpad` = 1 を有効化（管理者権限）

`+` や `` `aa `` だけ出る場合は、旧ファームウェア（標準 `UC()`）の可能性があります。再ビルド・左右 flash を確認してください。
