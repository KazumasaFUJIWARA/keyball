# Keyball44 my_keymap — レイヤー対応表

## レイヤー一覧

| QMK | 名称 | 開き方 |
|-----|------|--------|
| **L0** | ベース | 通常 |
| **L1** | マウス | F 長押し |
| **L2** | 記号・言語 | D 長押し |
| **L3** | **イタalia語アクセント** | L2 + 親指3番目 OSL |
| **L4** | 設定（RGB/CPI） | G/H 長押し |

ギリシャ・数学レイヤーは削除し、**イタalia語のみ** に統一。

## イタalia語文字を出す手順

| 順番 | キー |
|------|------|
| 1 | **D** 長押し（L2） |
| 2 | **親指・左から3番目** タップ（OSL(3)） |
| 3 | 母音キー（下表） |

OSL は **タップ1回**。離したあと **次の1キーだけ** L3 になる。

### L3 の主な割り当て

| キー位置（QWERTY 基準） | 出力 |
|------------------------|------|
| A | à |
| E（上段） | é |
| F | è |
| U | ù |
| I | ì |
| O | ò |
| P | á |

例: **è** → `D` → 親指3番目タップ → `F`

## L2 のその他

| キー | 機能 |
|------|------|
| F | 日本語（0x0090） |
| G | 英数（0x0091） |

記号キーは Remap dump どおり維持。

## Unicode（Windows）

- **英数（IME オフ）** + **メモ帳** で試す
- **テンキー NumLock ON**
